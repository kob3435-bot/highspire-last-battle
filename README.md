# The Last Battle of Highspire

Original-fantasy browser game: a 3D cinematic action RPG and large-scale battle simulation set during the final siege of Highspire castle (Three.js + TypeScript). This repository contains the compiled web build.

▶ **Play:** https://kob3435-bot.github.io/highspire-last-battle/

Features: 12-chapter story campaign (Thai/English), 41 anime-style characters, War Commander, Spectator, What If scenarios, free battle, explorable areas, replays, gamepad & touch controls. All visuals and audio are original procedural primitives and synthesized sound.
